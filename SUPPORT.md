# Support

## Have a question?

Use **GitHub Discussions** for:
- "How do I...?" questions
- Architecture/design questions about Actions, Blast Radius, riskMode, etc.
- Sharing what you've built with Cortera Framework

## Found a bug?

Open a **GitHub Issue** using the Bug Report template. Please check:
- The known-gaps list in `CONTRIBUTING.md` first (some things are already
  tracked, e.g. the CLI duplicate `keys` command bug)
- You're on the latest `@cortera/*` release

## Found a security issue?

**Do not use Issues or Discussions.** See `SECURITY.md` for private
reporting via GitHub's Security tab or security@cortera.space.

## Package-specific issues

Tag your issue with the relevant package label: `core`, `db`, `auth`,
`adapter-next`, `mcp`, `ui`, `guard-service`, `cli`.
